# 座学編

Webエンジニアになろう講習会の座学スライドです。
座学編で技術の全体像や背景をつかんだ後、対応する実習編で実際に手を動かして学びます。

::: tip 資料の見方
レイアウトされたスライドをそのまま読める**PDF 版がおすすめ**です。
ブラウザ上でスライドをめくりたい場合は HTML 版を利用できます。どちらも新しいタブで開きます。
:::
